# Changelog

## 1.8.0

- Add separate global and per-weapon direct-hit/explosion damage controls against vehicles, players and mobs.
- Support TACZ, SBW handheld/mounted projectile weapons and Create Big Cannons.
- Scale TACZ normal and armor-piercing portions consistently.
- Preserve CBC native source metadata while distinguishing direct hits from explosions.
- Synchronize damage tuning for Jade vehicle estimates.
- Add mounted weapon damage-tuning IDs to the armor scan.
- Rename distribution jars to `sbw-dmg-tweak-<version>.jar`.
- Separate the combat source repository from pack recipes and publishing materials.

## 1.7.0

- Add aircraft structural and engine damage profiles, repair behavior and inspection statistics.

## Earlier versions

- Add configurable TACZ explosion and CBC attribution compatibility.
- Add vehicle armor, attachment-aware penetration, mounted weapon support, component damage, impact feedback and inspection.
